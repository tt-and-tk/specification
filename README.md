# Pynthesis 仕様書

自作パソコンのプロジェクトPynthesisの仕様と，各リポジトリのソースを変更する開発の手順をまとめたものであり，各リポジトリの実装が参照する唯一の一次情報源である．  
Pynthesisの構成要素の名称と，Pynthesis全体で共通に使う用語は，[terms.md](terms.md)を参照．  

## 各文書

文書は，構成要素ごとのディレクトリに分けて置く．各構成要素の`develop/`には，そのソースを変更する人のための開発の手順を置く．各ディレクトリの`index.md`に，そのディレクトリのファイルとディレクトリの一覧を置く．  
各文書の先頭のフロントマターには，その文書に書いてあること(`description`)を書く．読者を限る文書には，想定する読者(`audience`)も書く．  
番地の上下は，番地の大きい側を上，小さい側を下と呼ぶ([qurge/memory.md](qurge/memory.md)の「容量と番地」を参照)．  

```
specification/
├── terms.md           構成要素の名称と，Pynthesis全体で共通に使う用語
├── operation.md       実機の準備・接続・起動のやり直し・実行ファイルを置く方法の手順
├── board.md           ボードとシールドの物理的な構成と，ピンの割り当て
├── qurge/             ハードウェアQurgeの仕様．起動の仕組み・メインメモリ・ROM
│   ├── cpu/           CPUの命令・レジスタ・スタック・動作状態・例外・割り込み・パイプライン
│   └── develop/       ソースの構成・Vivadoでの合成・シミュレーション・ビットストリームの書き込み
├── pyntaxis/          アセンブリ言語Pyntaxis
│   ├── language/      言語自体の仕様
│   ├── assembler/     アセンブラの使い方と，命令を機械語へ変換する方法
│   └── develop/       アセンブラのソースの構成・ビルド・テスト
├── pynesis/           プログラミング言語Pynesis
│   ├── language/      言語自体の仕様
│   ├── compiler/      コンパイラの使い方と，コンパイラが生成する命令
│   └── develop/       コンパイラのソースの構成・ビルド・実装の決まり・テスト
└── qosmos/            OS Qosmos
    ├── user/          利用者から見たQosmosの動作．起動時の表示・コンソール・シェル・組み込みコマンド・ファイル
    ├── program/       実行ファイルを作る人から見たQosmos．実行ファイルの作り方と，システムコールの使い方
    ├── kernel/        Qosmosの内部で，各機能を実現する仕組み
    └── develop/       Qosmosのソースの構成と，ROMの生成
```
