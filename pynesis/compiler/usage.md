# コンパイラの使い方
コンパイラは，Pynesisのソースファイル(`.pn`．[pynesis/language/overview.md](../language/overview.md)を参照)を，ROMとして埋め込むSystemVerilogのソース(`.sv`)，またはQosmosの実行ファイルへ変換する．  
ふだんは`pn2mc.exe`を使う．  

```
pn2mc.exe -pn qosmos.pn -pt qosmos.pt -sv rom_sv.sv    # ROMを出力する(QurgeのプロジェクトはROMをrom_sv.svから読む)
pn2mc.exe -pn hello.pn -pt hello.pt -bin HELLO          # 実行ファイルHELLOを出力する
```

コンパイラは，次の2つのツールから成る．  

| ツール | 変換する範囲 |
|:-|:-|
| `pn2asm.exe` | Pynesisのソース(`.pn`) → アセンブリ(`.pt`) |
| `pn2mc.exe` | Pynesisのソース(`.pn`) → SystemVerilogのROM(`.sv`)またはQosmosの実行ファイル．途中でアセンブリ(`.pt`)も出力する |

`pn2mc.exe`は，`pn2asm.exe`の本処理と，アセンブラ`asm2mc.exe`([pyntaxis/assembler/usage.md](../../pyntaxis/assembler/usage.md)を参照)の本処理を，順に呼び出す．  

# 共通事項
## 入力と出力
- 入力: ソースファイル(`.pn`)．`#include`で取り込んだファイル([pynesis/language/include.md](../language/include.md)を参照)と合わせて，1つのプログラムとしてコンパイルする  
- 出力: 起動引数で指定したファイル  

エラーになった場合に残るファイルは，次のとおりである．  

- 起動引数の誤りとコンパイルエラー: どのファイルも作らない  
- `pn2mc.exe`で，アセンブラの本処理がエラーになった場合: 途中で出力したアセンブリだけが残り，ROMと実行ファイルは作らない  

## コンパイルエラー
ソース上の位置を特定できるコンパイルエラーは，次の形で出力する．  

```
compiler error: <内容> at <ファイル名>:<行番号>
```

# pn2asm.exe
Pynesisのソースを，アセンブリへ変換する．  

```
pn2asm.exe -pn program.pn -pt program.pt               # ROM用のアセンブリを出力する
pn2asm.exe -pn program.pn -pt program.pt --bin-mode    # 実行ファイル用のアセンブリを出力する
```

## 入力するファイル(-pn)
入力するPynesisのソースファイル名を，`-pn`に続けて書く．  
`-pn`を付けずに書いた引数も，入力するファイル名として扱う．  
ファイル名は`.pn`で終わる必要がある．  
入力するファイル名が無い場合と，`.pn`で終わらない場合は，エラーになる．  

## 出力するファイル(-pt)
出力するアセンブリのファイル名を，`-pt`に続けて書く．  
省略した場合は，入力するファイル名の拡張子を`.pt`に変えた名前で出力する．  

## 出力先(--bin-mode)
`--bin-mode`は値を取らない．  
指定した場合は，Qosmosの実行ファイル用のアセンブリを出力する．  
指定しない場合は，ROM用のアセンブリを出力する．  

アセンブリは出力先の情報を持たない．  
このため，ROM用のアセンブリを`asm2mc.exe`の`-bin`で実行ファイルへ変換しても，誤りとして検出されない．  
実行ファイルを作る場合は，`--bin-mode`で出力したアセンブリを`asm2mc.exe`の`-bin`で変換する．  

## 同じ引数を複数回指定した場合
同じフラグや，`-pn`を付けない引数を複数回指定した場合は，エラーにはならず，最後に指定した値を使う．  

# pn2mc.exe
Pynesisのソースを，SystemVerilogのROMまたはQosmosの実行ファイルへ変換する．  

## 入力するファイル(-pn)
入力するPynesisのソースファイル名を，`-pn`に続けて書く．  
省略できない．  

## 途中で出力するアセンブリ(-pt)
途中で出力するアセンブリのファイル名を，`-pt`に続けて書く．  
省略できない．  

## ROMとして出力するファイル(-sv)
`-sv`を指定すると，ROM用のアセンブリを生成してから，SystemVerilogのROMへ変換する．  
出力するファイル名を，`-sv`に続けて書く．  
`-sv`も`-bin`も指定しない場合は，`-pt`のファイル名の拡張子を`.sv`に変えた名前で，ROMを出力する．  

## 実行ファイルとして出力するファイル(-bin)
`-bin`を指定すると，実行ファイル用のアセンブリを生成してから，Qosmosの実行ファイルへ変換する．  
出力する実行ファイルの名前を，`-bin`に続けて書く．  
名前の規則は，`asm2mc.exe`の`-bin`と同じである([pyntaxis/assembler/usage.md](../../pyntaxis/assembler/usage.md)の「実行ファイルとして出力するファイル(-bin)」を参照)．  

## 引数の誤り
次の引数は誤りとして，変換を始める前に，どのファイルも作らずにエラーにする．  

- `-sv`と`-bin`の両方: 出力先を1つに決められないため  
- `-pn`などのフラグを付けない引数: `pn2asm.exe`は入力するPynesisのソース，`asm2mc.exe`は入力するアセンブリと解釈が異なり，どちらに合わせても紛らわしいため  
- `-pn`・`-pt`・`-sv`・`-bin`以外のフラグと，値の無いフラグ: 打ち間違いに気づけるようにするため  

## 同じ引数を複数回指定した場合
同じフラグを複数回指定した場合は，エラーにはならず，最後に指定した値を使う．
