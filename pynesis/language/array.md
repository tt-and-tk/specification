# 配列
```c
int table[10];               // int型の要素10個の配列
char msg[] = "hello";        // 文字列で初期化する(サイズは6)

void fill(char *dst, int n) {    // 配列はポインタで受け取る
    for (int i = 0; i < n; i++) {
        dst[i] = ' ';
    }
}

void main(void) {
    table[0] = 1;
    table[1 + 1] = table[0];     // 添字には式を書ける
    fill(msg, 5);                // 配列を渡すと先頭要素の番地が渡る
}
```

宣言できるのは，サイズを固定した1次元の配列だけである(`int table[10]`，`char buf[64]`，`short arr[4]`，`char *names[4]`)．  
サイズは定数式([pynesis/language/variable.md](variable.md)の「定数式」を参照)で指定する．  
サイズを省略できるのは，文字列リテラルで初期化する場合だけである(「配列の初期化子」を参照)．  
配列の初期化子には，サイズを省略した`char`・`unsigned char`の配列への文字列リテラルだけを書ける．初期値リスト(`{1, 2, 3}`)は書けない．  
初期化子のない配列の要素の値は保証されない．  

配列は要素ごとに読み書きする．  
添字には変数を含む式も書ける(`buf[i]`，`table[i + 1] = x`)．  
添字の範囲は，コンパイル時・実行時とも検査しない．  
C言語と同じく，範囲外の読み書きの結果は保証しない．  
配列そのもの(`buf`・`v.array`など)は，代入・`++`/`--`の対象にできない．  

要素の型が8/16ビットの配列も，要素ごとに読み書きできる．  
読み出しと格納の規則は，8/16ビットの型の変数と同じである([pynesis/language/type.md](type.md)の「読み出しと格納」を参照)．  

# 値として使う配列
配列を値として使うと，先頭要素へのポインタになる．  
対象になる配列は，配列変数・構造体のメンバの配列・構造体の配列の要素のメンバの配列・文字列リテラルである．  
値として使うのは，次の位置に書く場合である．  
ただし，組み込み関数の引数と，`char msg[] = "hello";`の初期化子の文字列リテラルは除く(「値として使わない配列」を参照)．  

- 代入の右辺  
- 初期化子  
- 引数  
- 戻り値  
- 演算のオペランド  
- if文・while文などの条件  
- 式文  
- for文の3つ目の式(`for (int i = 0; i < n; i++)`の`i++`の位置)  

このため，関数の引数に配列を渡すと，先頭要素の番地が渡る．  
格納先(代入先・初期化する変数・引数・戻り値)の型は，要素の型へのポインタでなければならない．  

```c
struct Entry {
    char name[8];
};
struct Entry entries[4];
char buf[16];

void main(void) {                  // fillは，この文書の冒頭の例で定義した関数
    fill(buf, 16);                 // bufの先頭要素の番地を渡す
    fill(entries[1].name, 8);      // 構造体の配列の要素のメンバの配列も渡せる
}
```

## 値として使わない配列
次の2つは，配列のまま扱う．  

- 組み込み関数の引数([pynesis/language/builtin.md](builtin.md)の「文字列の組み込み関数」を参照)  
- `char msg[] = "hello";`の初期化子の文字列リテラル  

関数の引数を配列の形(`char msg[]`)で宣言することはできない．  
ポインタ(`char *msg`)で宣言する．  

# 文字列
文字列リテラル([pynesis/language/lexical.md](lexical.md)の「文字列リテラル」を参照)は，次の2つの使い方ができる．  

## 配列の初期化子
`char msg[] = "hello";`のように，サイズを省略した配列の宣言の初期化子に使える．  
サイズを書いた配列(`char msg[6] = "hello";`)は，文字列リテラルで初期化できない．  

配列のサイズは，文字列の長さ+1(ヌル終端の分)で決まる．  
初期化できるのは`char`または`unsigned char`の配列で，各要素に文字コードを格納する．  

## 式の中の文字列
配列の初期化子以外の式の中(関数呼び出しの引数など)では，名前のないグローバルの`char`の配列として扱う．  

内容は1回だけメモリへ書き込まれ，以降は同じ番地を参照する．  
書き込む時点は，[pynesis/language/function.md](function.md)の「main関数」を参照．  
配列と同じく，値として使うと先頭要素へのポインタ(`char *`)になる．
