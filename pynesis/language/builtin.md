# 組み込み関数
標準ライブラリは提供しない．  
代わりに，次の組み込み関数を提供する．  

```c
char name[8];
char input[8];

int main(void) {
    strcopy(name, "bin");                  // nameへ"bin"をコピーする
    if (streq(name, input)) {              // nameとinputの内容が一致するか
        return 1;
    }
    return syscall(4, (int)name, 3, 0, 0); // 番号4のシステムコールを呼ぶ
}
```

| 関数 | 説明 |
|:-|:-|
| `streq(a, b)` | `char`配列`a`・`b`の内容が一致するか比較し，一致すれば`1`，不一致なら`0`を返す(`int`) |
| `strcopy(dst, src)` | `char`配列`src`の内容を，ヌル終端付きで`char`配列`dst`へコピーする |
| `syscall(number, a, b, c, d)` | 番号`number`のシステムコールを引数`a`〜`d`を渡して呼び，OSが返した戻り値を返す(`int`) |
| `sysret()` | ユーザーモードへ移り，KRETの番地へ飛ぶ．値を返さない(`void`) |

組み込み関数の名前は予約語であり，同じ名前の変数・関数は宣言できない(宣言した時点でコンパイルエラーになる)．  

組み込み関数は，通常の関数と異なり，呼び出した箇所へ命令の並びを直接展開する．  
このため，戻り先はスタックへ積まれない([pynesis/compiler/call.md](../compiler/call.md)の「組み込み関数の展開」を参照)．  

# 文字列の組み込み関数
`streq`・`strcopy`の引数には，`char`型または`unsigned char`型の配列を渡す．  
引数は配列のまま受け取り，先頭要素へのポインタとしては扱わない([pynesis/language/array.md](array.md)の「値として使う配列」を参照)．  

## 渡せる引数
配列を表す引数のうち，渡せるかどうかと渡せない理由は，要素の型の符号によらず次のとおりである．  

| 引数 | 渡せるか | 渡せない理由 |
|:-|:-|:-|
| 固定サイズで宣言した配列変数(`buf`) | ○ | |
| 1つの構造体変数のメンバの配列(`entry.name`) | ○ | |
| 番地が実行時に決まるメンバの配列(`arr[i].name`・`p->name`) | × | 各関数は，配列の先頭の番地を変数の宣言から求める．添字やポインタの値から番地を計算する命令は生成しない |
| ポインタ(`char *p`) | × | 各関数は，配列の宣言サイズで打ち切りを判定する．ポインタからは，指す先の配列の宣言サイズが分からない |

## streq
先頭から1文字ずつ，次の順に判定する．  

1. 2つの配列の宣言サイズの小さい方に達した場合は，不一致(`0`)を返す．ヌル終端が見つからないまま宣言サイズに達したとみなし，安全のため不一致として扱う  
2. 2つの文字が異なる場合は，不一致(`0`)を返す．片方だけが先にヌル終端に達した場合も，これに当たる  
3. 2つの文字がともにヌル終端の場合は，一致(`1`)を返す  
4. どれにも当たらない場合は，次の文字へ進む  

## strcopy
`src`の先頭から，ヌル終端の手前までの文字を`dst`へコピーし，最後にヌル終端を書き込む．  
コピーする文字数が`dst`の宣言サイズ-1に達した場合は，そこで打ち切ってヌル終端を書き込む．  
`src`の宣言サイズは打ち切りの判定に使わない．  

# システムコールを呼ぶ組み込み関数
`syscall(number, a, b, c, d)`は，Qosmosのシステムコールを番号で呼ぶ．  
実行ファイルからシステムコールを呼ぶには，ふだんはQosmosのライブラリ`lib/syscall.pn`の関数(`file_read`など)を使う．  
ライブラリの関数は，内部でこの組み込み関数を呼ぶ．  
ライブラリの使い方と，番号と機能の対応は，[qosmos/program/syscall.md](../../qosmos/program/syscall.md)を参照．  
番号は，ライブラリが取り込む`syscall_number.pn`に定数として定義されている．  

OSが戻ると，OSが書き込んだ戻り値を`syscall`の値として，次の処理へ進む．  

引数は，5つとも`int`として渡す．  
関数の`int`型の引数と同じく，ポインタを渡すとコンパイルエラーになる([pynesis/language/pointer.md](pointer.md)の「型の一致」を参照)．  
ポインタは`int`へキャストして渡す．  
機能が使わない引数には，`0`などを渡す．  
戻り値の型は`int`である．  

番号と引数をOSへ渡すために生成する命令の並びは，[pynesis/compiler/call.md](../compiler/call.md)の「システムコールの呼び出し」を参照．  

# ユーザーモードへ移る組み込み関数
`sysret()`は，OSが実行ファイルへ移るために使う．  
実行ファイルを始めるときと，システムコールから実行ファイルへ戻るときに使う([qurge/cpu/mode.md](../../qurge/cpu/mode.md)の「動作状態の切り替え」を参照)．  

`sysret()`は引数を取らない．  
ユーザーモードにして，KRETの番地へ飛ぶ．  
`sysret()`の後に書いた文へは進まない．  
実行ファイルが組み込み関数`syscall`でカーネルモードへ入った後なら，KRETは，その`syscall`の呼び出しの直後を指している．  

ユーザーモードで実行すると例外になるため，実行ファイルでは使えない(コンパイルエラー)．
