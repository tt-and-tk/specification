# 列挙型
```c
enum State {                  // 列挙型の定義
    IDLE,                     // 0
    RUNNING,                  // 1
    WAITING = 5,              // 値を明示する
    DONE,                     // 6(直前の値に1を足す)
};
enum { CAP = 4 };             // 無名の列挙型

void main(void) {
    enum State s = RUNNING;   // 列挙型の変数(intと同じ)
    switch (s) {
        case DONE:            // 列挙子は定数式に書ける
            s = IDLE;
            break;
    }
}
```

列挙型は，名前付きの整数定数(列挙子)の組を定義する．  

# 定義
列挙型の定義は，次の2つの形に対応する．  
いずれも，グローバルスコープの直下にだけ書ける．  

```c
enum Tag { A, B = 3, C };    // 列挙型名を付けた定義
enum { D, E };               // 無名の列挙型．列挙子だけを定義する
```

列挙子はカンマで区切り，最後の列挙子の後ろにもカンマを書ける．  
列挙子を1つも持たない定義は，コンパイルエラーになる．  

列挙型名・列挙子の名前空間と参照できる範囲は，[pynesis/language/scope.md](scope.md)を参照．  

# 列挙子の値
列挙子の値は，次のとおり決まる．  

- `名前 = 定数式`と書いた列挙子: 定数式の値([pynesis/language/variable.md](variable.md)の「定数式」を参照)  
- 値を省略した先頭の列挙子: `0`  
- 値を省略したそれ以外の列挙子: 直前の列挙子の値に1を足した値  

値は`int`の範囲に収める．  
範囲を外れると，コンパイルエラーになる(`= 0xFFFFFFFF`や，`2147483647`の次の値を省略した列挙子)．  
定数式の計算と異なり，`int`の最大値に1を足した値を折り返さない．  
同じ値の列挙子は，同じ列挙型の中でも書ける．  

値を省略した列挙子の値は，直前の列挙子の値で決まる．  
このため，`enum { A = C, B, C };`は，Aの値がAへ戻ってくる循環した依存になり，コンパイルエラーになる([pynesis/language/scope.md](scope.md)の「名前が指す宣言」を参照)．  

# 列挙子の扱い
列挙子は，型が`int`の定数であり，次のとおり扱う．  

- メモリを確保せず，参照する箇所へ値を直接埋め込む  
- 定数式([pynesis/language/variable.md](variable.md)の「定数式」を参照)に書ける  
- 値を書き換える操作・`&`による番地の取得は，コンパイルエラーになる  
- `sizeof(列挙子)`は`4`である  

列挙子についてのエラーメッセージでは，列挙子を`const variable`と表示する(`value of const variable 'A' is out of range for its type`)．  

# 列挙型の変数
`enum 列挙型名`は，`int`と同じ型の型名であり，変数の宣言やキャストのように`int`を書けるすべての場所に書ける．  
定義されていない列挙型名を書くと，コンパイルエラーになる．  

`enum Tag`と`int`は区別しない．  
`enum Tag *`と`int *`も同じ型であり，相互に代入できる．  
エラーメッセージでは，`enum Tag`を`int`と表示する．  
列挙子でない値も，検査せずに格納できる(C言語と同じ)．  

# 対応しない書き方
次のものには対応しない(コンパイルエラー)．  

- 関数の中での定義: 定義はグローバルスコープの直下にだけ書ける  
- 定義と同時の変数の宣言(`enum Tag { A } v;`): 定義と変数の宣言を分けて書く  
- 列挙子を持たない宣言(`enum Tag;`)  
- 定義への`static`: 列挙型名と列挙子は，プログラム全体で共有する  
- 符号修飾子との組み合わせ(`unsigned enum Tag`)
