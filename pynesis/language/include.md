# ソースファイルの取り込み
`#include "パス"`を書くと，その位置に指定したファイルの内容が書かれていたものとして，1つのプログラムにまとめてコンパイルする．  

```c
// main.pn
#include "lib/io.pn"      // main.pnがあるディレクトリのlib/io.pnを取り込む
void main(void) {
    put_line("hello");    // lib/io.pnで定義した関数を呼ぶ
}
```

```c
// lib/io.pn
#pragma once              // 複数のファイルから取り込まれても1回だけ取り込む
void put_line(char *s) {
    // 文字列を出力する処理
}
```

# #include
パスは`"`で囲む．  
`<...>`の形には対応しない．  
パスは，取り込み指令を書いたファイルがあるディレクトリからの相対パス，または絶対パスで書く．  
取り込むファイルの拡張子は`.pn`に限る．  

指令の`#`は行の1文字目に書く．  
前に空白を置けない．  
指令の後ろの同じ行には，コメントだけを書ける．  

取り込んだファイルの宣言は，取り込み元の宣言と区別なく，プログラム全体から参照できる([pynesis/language/variable.md](variable.md)の「グローバルスコープ」を参照)．  

## 書ける位置
1つのファイルに書いた宣言は，そのファイルの中で完結させる．  
指令は，グローバルスコープの宣言と宣言の間にだけ書ける．  
次の場合はコンパイルエラーになる．  

- ファイルが宣言の途中で終わる  
- 関数の本体・構造体の定義の中に指令を書く  
- 宣言の途中に指令を書く  

## 同じファイルを2回以上取り込む場合
`#pragma once`が書かれていないファイルを1回のコンパイルで2回以上取り込むと，コンパイルエラーになる．  
次の場合も，2回以上の取り込みに当たる．  

- 別のファイルを経由して，間接的に重複して取り込む場合  
- コンパイラの`-pn`で指定したファイル自身を取り込む場合  
- 取り込みが循環する場合(`a.pn`が`b.pn`を，`b.pn`が`a.pn`を取り込むなど)  

# #pragma once
ファイルに`#pragma once`を書くと，そのファイルの2回目以降の取り込みは，エラーにならずに無視される．  
複数のファイルから共通に取り込むファイルに書く．  

`#include`と同じく，宣言と宣言の間であればどこに書いてもよい．  
同じファイルに複数回書いてもよい．  
`#pragma`に`once`以外を書くと，コンパイルエラーになる．  

効果は，`#pragma once`を読んだ時点から生じる．  
取り込みが循環する場合，そのファイルの字句解析の途中で再び取り込まれるため，循環のもとになる`#include`より前に書いておく必要がある．  
ファイルの先頭に書くことを勧める．  

# ほかの指令
`#include`・`#pragma once`以外の指令(`#define`など)は，コンパイルエラーになる．  
定数の定義には，const変数を使う([pynesis/language/variable.md](variable.md)の「const変数」を参照)．
