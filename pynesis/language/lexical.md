# 字句
```c
// 行コメント
/* ブロックコメント */
int count = 0x1F;          // 識別子count，16進の整数リテラル
char c = '\n';             // 文字リテラル(エスケープシーケンス)
char msg[] = "hello";      // 文字列リテラル
```

# 識別子
変数名・関数名などの識別子は，アルファベットまたは`_`で始まり，以降はアルファベット・数字・`_`だけで構成する．  
ただし，数値やレジスタとして読める綴り(`fh`・`r5`など)の関数名は，アセンブラが受け付けない([pyntaxis/language/program.md](../../pyntaxis/language/program.md)の「関数名にできない綴り」を参照)．  

# 整数リテラル
| 記法 | 例 |
|:-|:-|
| 10進 | `10`，`255` |
| 16進(`0x`または`0X`に続けて1桁以上の16進数字) | `0x0f`，`0XFF` |

整数リテラルの型は`int`である．  
ただし，`int`で表せない`0x80000000`以上の値(16進でだけ書ける)は`unsigned int`になる(C言語と同じ)．  
負の値は，リテラルに単項マイナスを付けて表す．  

## 書ける値の範囲
10進は`0`〜`2147483647`，16進は`0x0`〜`0xFFFFFFFF`を書ける．  
範囲外はコンパイルエラーになる．  

`int`の最小値(`-2147483648`)は，10進の整数リテラルでは書けない．  
`2147483648`が10進で書ける範囲を超えるためである．  
16進の`-0x80000000`は，`unsigned int`の`0x80000000`になる([pynesis/language/type.md](type.md)の「型変換」を参照)．  
`(int)0x80000000`や`-2147483647 - 1`と書けば表せる．  

## C言語と異なる点
C言語と異なる点は，次のとおりである．  

- 先頭が`0`でも，8進ではなく10進として読む(`010`は`10`)  
- 型を指定する接尾辞(`10u`など)は書けない．小さい値を符号なしとして扱うには，`(unsigned int)10`のようにキャストする([pynesis/language/type.md](type.md)の「キャスト」を参照)  

# 文字リテラル
ASCIIの1文字，またはエスケープシーケンス1つを`'`で囲む(`'a'`，`'\n'`)．  
空(`''`)や2文字以上は，コンパイルエラーになる．  
型は`char`，値はその文字の文字コードである．  

# 文字列リテラル
文字とエスケープシーケンスの並びを`"`で囲む(`"hello"`)．  
途中で改行することはできない．  
隣り合う文字列リテラルは，1つに連結される(`"C" "D"`は`"CD"`)．  
間に空白・改行・コメントを挟んでも連結される．  

文字列リテラルの使い方は，[pynesis/language/array.md](array.md)の「文字列」を参照．  

# エスケープシーケンス
文字リテラル・文字列リテラルで共通に使える．  

| 記法 | 意味 |
|:-|:-|
| `\n` | 改行 |
| `\t` | タブ |
| `\r` | 復帰 |
| `\0` | ヌル文字 |
| `\\` | `\` |
| `\'` | `'` |
| `\"` | `"` |

表にない文字を`\`の後に書くと，`\`を取り除いた次の1文字そのものになる(`\a`は`a`)．  

## 数値によるエスケープ
`\x41`・`\101`のような数値によるエスケープには対応しない．  
8進の表記を書いた場合の扱いは，次のとおりである．  

- 文字列リテラルの中: `\0`とそれに続く数字として読む(`"\012"`は`\0`・`1`・`2`の3文字)  
- 文字リテラルの中(`'\012'`): コンパイルエラーになる  

# コメント
コメントは，次の2種類である．  

- `//`から行末までが，行コメントになる  
- `/*`から`*/`までが，ブロックコメントになる
