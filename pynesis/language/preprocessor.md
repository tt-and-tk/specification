# 指令
`#`で始まる行は指令であり，コンパイラへの指示を表す．  
C言語のプリプロセッサ指令にあたる．  
対応する指令は，次の2つである．  

- `#include`: ほかのソースファイルを取り込む  
- `#pragma once`: 同じファイルの2回目以降の取り込みを無視させる  

```c
// main.pn
#include "lib/io.pn"      // main.pnがあるディレクトリのlib/io.pnを取り込む
void main(void) {
    put_line("hello");    // lib/io.pnで定義した関数を呼ぶ
}
```

```c
// lib/io.pn
#pragma once              // 複数のファイルから取り込まれても1回だけ取り込む
void put_line(char *s) {
    // 文字列を出力する処理
}
```

## 指令の書き方
指令の書き方の決まりは，次のとおりである．  

- `#`は行の1文字目に書く．前に空白を置けない  
- `#`と指令名の間に空白を置けない  
- 指令の後ろの同じ行には，コメントだけを書ける  

## 書ける位置
指令は，グローバルスコープに置く宣言と宣言の間にだけ書ける．  
ここでの宣言は，グローバル変数の宣言・関数の定義・構造体の定義のように，ファイルの直下に置く1つ1つの記述を指す([pynesis/language/variable.md](variable.md)の「グローバルスコープ」を参照)．  
次の場合はコンパイルエラーになる．  

- 関数の本体・構造体の定義の中に指令を書く  
- 1つの宣言の途中に指令を書く(`int`の行と`x;`の行の間など)  

# #include
`#include "パス"`の行は，指定したファイルの内容がその位置に書かれていたものとして扱われる．  
取り込み元と取り込んだファイルは，1つのプログラムとしてまとめてコンパイルされる．  

パスは`"`で囲む．  
`<...>`の形には対応しない．  
パスは，`#include`を書いたファイルがあるディレクトリからの相対パス，または絶対パスで書く．  
取り込むファイルの拡張子は`.pn`に限る．  

取り込んだファイルの宣言は，取り込み元の宣言と区別なく，プログラム全体から参照できる([pynesis/language/variable.md](variable.md)の「グローバルスコープ」を参照)．  
ただし，`static`を付けた宣言は，宣言したファイルの中からだけ参照できる．  
取り込み元からも参照できない([pynesis/language/variable.md](variable.md)の「static」を参照)．  

## ファイルの終わり
どのファイルも，宣言の途中で終わるとコンパイルエラーになる．  
2つのファイルにまたがって1つの宣言を書くことはできない．  
例えば，`int`で終わるファイルを取り込み，取り込み元の次の行に`x;`と書くと，コンパイルエラーになる．  

## 同じファイルを2回以上取り込む場合
`#pragma once`が書かれていないファイルを1回のコンパイルで2回以上取り込むと，コンパイルエラーになる．  
宣言の重複の有無は問わず，空のファイルでもコンパイルエラーになる．  
同じファイルかどうかはパスで判定し，`lib/../lib/io.pn`のように別の書き方をしたパスも同じファイルとみなす．  
次の場合も，2回以上の取り込みに当たる．  

- 別のファイルを経由して，間接的に重複して取り込む場合  
- コンパイラの`-pn`で指定したファイル自身を取り込む場合  
- 取り込みが循環する場合(`a.pn`が`b.pn`を，`b.pn`が`a.pn`を取り込むなど)  

# #pragma once
ファイルに`#pragma once`を書くと，そのファイルの2回目以降の取り込みは，エラーにならずに無視される．  
複数のファイルから共通に取り込むファイルに書く．  

`#include`と同じく，宣言と宣言の間であればどこに書いてもよい．  
同じファイルに複数回書いてもよい．  
`#pragma`に`once`以外を書くと，コンパイルエラーになる．  

コンパイラは，ファイルを先頭から読み，`#include`の行に達すると取り込むファイルを読み終えてから続きを読む．  
`#pragma once`の効果は，コンパイラがその行を読んだ後の取り込みにだけ生じる．  
そのため，取り込みが循環する場合は，循環のもとになる`#include`より前に`#pragma once`を書いておく必要がある．  
例えば，`a.pn`の`#include "b.pn"`より後ろに`#pragma once`を書くと，`b.pn`が`a.pn`を取り込む時点ではまだ効果が生じておらず，コンパイルエラーになる．  
ファイルの先頭に書くことを勧める．  

# 対応しない指令
C言語の指令のうち，`#include "パス"`・`#pragma once`以外には対応しない．  
書くと，コンパイルエラーになる．  
代わりの書き方は，次のとおりである．  

| C言語の指令 | 代わりの書き方 |
|:-|:-|
| `#define`による定数の定義 | const変数([pynesis/language/variable.md](variable.md)の「const変数」を参照) |
| `#define`による引数付きのマクロ | 関数([pynesis/language/function.md](function.md)を参照) |
| `#ifndef`・`#define`・`#endif`による取り込みの重複の防止 | `#pragma once`(「#pragma once」を参照) |
| `#undef`・`#if`・`#ifdef`・`#elif`・`#else`・`#endif`・`#error`・`#line` | なし |
| `#include <...>` | なし．標準ライブラリの代わりに組み込み関数を使う([pynesis/language/builtin.md](builtin.md)を参照) |
| `#pragma`の`once`以外の指定 | なし |
