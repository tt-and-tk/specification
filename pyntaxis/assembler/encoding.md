# 機械語への変換
アセンブラは，アセンブリの1つの命令を，QurgeのCPUの1つの命令([qurge/cpu/isa.md](../../qurge/cpu/isa.md)を参照)へ変換する．  

# 引数と機械語のフィールド
アセンブリの命令の名前は，同じ綴りの機械語の命令(大文字で表す)に対応する．  
アセンブリに書いた引数は，命令の書き方([pyntaxis/language/instruction.md](../language/instruction.md)を参照)の例で同じ名前を付けたフィールドへ入れる．  
例の名前と異なるのは，次の引数である．  

- `jmp`・F系の局所ラベルと，`call`の関数名: 「名前の解決」の値にして，immへ入れる  
- `call`のレジスタ: rs1へ入れる  
- `div`・`divu`の4つ目の引数: immへ入れる  

- immを書いた場合は，即値使用フラグ(imm[32])を1にする．immを省略した場合は，フラグとイミディエイトデータを0にする  
- 引数に対応しないフィールドは0にする  
- immを省略できる命令は，immを書いた形と省略した形を，引数の個数で区別する  
- `call`は，関数名を書いた形とレジスタを書いた形を，引数の書き方で区別する  

# 名前の解決
関数名と局所ラベルは，アセンブリ全体を読んで位置を決めてから，次の値に置き換える．  
関数名の書き方は[pyntaxis/language/program.md](../language/program.md)の「関数」と「関数のPC」を，局所ラベルの書き方は[pyntaxis/language/label.md](../language/label.md)を参照．  
命令の位置(index)は，プログラムの先頭の命令を0として数えた命令の順番である．  
先頭の命令のPCは0のため，indexはそのままPCになる．  

| 書いた場所 | 置き換える値 | 理由 |
|:-|:-|:-|
| イミディエイトデータの位置と`call`の関数名 | 関数の先頭の命令のPC | 呼び出し先と関数のPCは，プログラムの先頭からの位置で表すため |
| `jmp`の局所ラベル | 局所ラベルの位置のPC | `jmp`は`PC = imm`で飛ぶため |
| F系の局所ラベル | 局所ラベルのindexから，このF系の命令のindexを引いた値 | F系は条件が成り立つと`PC += imm`で飛ぶため |

F系の値は，前にある局所ラベルへ飛ぶ場合に負になる．  
イミディエイトデータは32ビットの2の補数として扱うため，前にも後ろにも飛べる．  

```
    rm  fh r0 r0 4      ; index 0
    rm  fh r0 r1 8      ; index 1
    egt r0 r1 .L0       ; index 2: imm = 4 - 2 = 2
    mov fh r0 r0 1      ; index 3
.L0:                    ; index 4の位置
    wm  fh r0 r0 12     ; index 4
.L1:                    ; index 5の位置
    rm  fh r0 r0 4      ; index 5
    lt  r0 r1 .L1       ; index 6: imm = 5 - 6 = -1
    jmp .L1             ; index 7: imm = 5
```

# mainのretの扱い
ROMへ出力する場合は，`main`の中のすべての`ret`を，自分自身へ飛ぶ`jmp`に置き換える．  
`main`はプログラムの開始点で戻り先を持たないため，`ret`の代わりに同じ命令を実行し続けてその場で止まる．  

実行ファイルへ出力する場合は，`main`の`ret`も，ほかの関数と同じく`ret`の命令にする．  

# 出力の形式
## ROM
SystemVerilogのROMのモジュール`rom_sv`を出力する．ROMの動作は[qurge/rom.md](../../qurge/rom.md)を参照．  
各命令は，機械語を作る関数(`machine.svh`)の呼び出しとして書く．関数の引数は，アセンブリに書いた引数の順に並べる．  

## 実行ファイル
1つの命令の機械語は8バイトである．  
各命令の機械語を，先頭から順に並べる．  
ヘッダは持たない．  
各命令のバイトの並びは，[qurge/cpu/isa.md](../../qurge/cpu/isa.md)の「基本構成」を参照．
