# アセンブラの使い方
アセンブラ`asm2mc.exe`は，アセンブリ言語Pyntaxis([pyntaxis/language/program.md](../language/program.md)を参照)で書いたファイル(`.pt`)を，次のどちらかへ変換する．  
名前のmcは機械語(machine code)を表し，出力するファイルの種類によらず同じ名前を使う．  

- ROMとして埋め込むSystemVerilogのソース(`.sv`)  
- Qosmosの実行ファイル  

```
asm2mc.exe -pt program.pt -sv program.sv    # ROMを出力する
asm2mc.exe -pt program.pt                   # ROMを出力する(program.svになる)
asm2mc.exe -pt hello.pt -bin HELLO          # 実行ファイルHELLOを出力する
```

# 起動引数
## 入力するファイル(-pt)
入力するアセンブリのファイル名を，`-pt`に続けて書く．  
`-pt`を付けずに書いた引数も，入力するファイル名として扱う．  
ファイル名は`.pt`で終わる必要がある．  
入力するファイル名が無い場合と，`.pt`で終わらない場合は，エラーになる．  

## ROMとして出力するファイル(-sv)
出力するSystemVerilogのROMのファイル名を，`-sv`に続けて書く．  
ファイル名は`.sv`で終わる必要があり，終わらない場合はエラーになる．  
`-sv`も`-bin`も指定しない場合は，入力するファイル名の拡張子を`.sv`に変えた名前で出力する．  

## 実行ファイルとして出力するファイル(-bin)
`-bin`を指定すると，ROMの代わりに実行ファイルを出力する．  
出力する実行ファイルの名前を，`-bin`に続けて書く．  
`-sv`と`-bin`を両方指定した場合は，エラーになる．  

名前のうち，ディレクトリを除いたファイル名の部分は，次の両方を満たす必要がある．  
満たさない名前はエラーになる．  

- Qosmosの名前の規則([qosmos/user/file.md](../../qosmos/user/file.md)の「名前の規則」を参照)に従う  
- 拡張子を持たない．Qosmosは拡張子の無いファイルだけを実行ファイルとして探すため  

## 同じ引数を複数回指定した場合
同じフラグや，`-pt`を付けない引数を複数回指定した場合は，エラーにはならず，最後に指定した値を使う．  

# エラー
アセンブリに誤りがある場合と，命令数が上限([pyntaxis/language/target.md](../language/target.md)の「命令数の上限」を参照)を超える場合は，エラーになる．  
エラーになった場合は，出力ファイルを作らない．
