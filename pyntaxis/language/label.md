# 局所ラベル
局所ラベルは，関数の中で飛ぶ先を表す名前である．  
`jmp`と分岐系の命令の飛び先に書く([pyntaxis/language/instruction.md](instruction.md)を参照)．  

```
main:
    rm  fh r0 r0 4      ; r0 = 4番地の値
    rm  fh r0 r1 8      ; r1 = 8番地の値
    egt r0 r1 .L0       ; r0 >= r1なら.L0へ飛び，次の2行を飛ばす
    mov fh r0 r2 1      ; r2 = 1
    wm  fh r0 r2 12     ; 12番地へr2を書き込む
.L0:
    rm  fh r0 r1 8      ; 飛んでも飛ばなくても，ここへ進む
.L1:
    sub r1 r2 r1        ; r1 = r1 - r2
    lt  r0 r1 .L1       ; r0 < r1なら.L1へ戻る(前にある局所ラベルへも飛べる)
    ret
```

# 定義
局所ラベルは，`.`で始まる名前に`:`を付けて，行頭から単独の行に書く(例: `.L0:`)．  

- 局所ラベルは命令を生成せず，直後の命令の位置を表す  
- `.global`宣言は要らない．先頭の`.`で関数名と区別する  
- 局所ラベルは，定義した行の直前にある関数ラベルの関数に属する  
- 関数の末尾(最後の命令の後)に書いた局所ラベルも，定義した関数に属する  
- どの関数にも属さない位置(`main:`より前)には定義できない  
- 局所ラベルの名前は，プログラム全体で一意にする．関数が異なっても，同じ名前は使えない．アセンブラが，全関数の局所ラベルを1つの表で解決するためである  

Pynesisのコンパイラが出力するアセンブリでは，局所ラベルに連番(`.L0`，`.L1`，…)を付けて一意にする．  
Pynesisの識別子は`.`で始まらないため，関数名と局所ラベルは衝突しない([pynesis/language/lexical.md](../../pynesis/language/lexical.md)の「識別子」を参照)．  

# 参照
- `jmp`と分岐系の命令の飛び先には，局所ラベルだけを書ける．数値やレジスタでは指定できない  
- 飛び先の局所ラベルは，参照する命令と同じ関数の中に定義されている必要がある  
- 定義より前の行からも参照できる
