# プログラムの書き方
Pyntaxisは，QurgeのCPUの命令([qurge/cpu/isa.md](../../qurge/cpu/isa.md)を参照)を1行に1つずつ書くアセンブリ言語である．  
プログラムは関数の並びとして書き，`main`から実行を始める．  

```
; プログラムの先頭には，空行とコメント行だけを書ける
.global main, get_num   ; プログラムで使うすべての関数名を挙げる

main:                   ; 関数ラベル．最初の関数はmainにする
    call get_num        ; get_numを呼び出す
    mov fh r0 r2 10     ; r2に10を代入する
    add r1 r2 r3        ; r3 = r1 + r2
    ret                 ; mainを終える

get_num:
    mov fh r0 r1 42     ; r1に42を代入する
    ret                 ; 呼び出し元へ戻る
```

各命令の書き方は[pyntaxis/language/instruction.md](instruction.md)，関数の中で飛ぶ先の書き方は[pyntaxis/language/label.md](label.md)を参照．  

# 行の書き方
1行には，命令・ラベル・`.global`宣言のどれか1つを書く．  
`;`以降は行末までコメントになる．  

命令はインデントして書く．  
ラベル(関数ラベルと局所ラベル)と`.global`宣言は，インデントせず行頭から書く．  
インデントは半角スペースで行う．  
タブ文字には対応しない．  

命令の名前と引数，引数どうしは，半角スペースで区切る．  

# 関数
関数は，関数ラベル`<関数名>:`の次の行から，次の関数ラベルの手前までである．  
`main`は必ず書き，プログラムの最初の関数にする．  
どの関数にも，`ret`を1つ以上置く．  
`ret`の位置と個数は問わない．  

ループ命令はない．  
繰り返しは，分岐系の命令と局所ラベルで書く([pyntaxis/language/label.md](label.md)を参照)．  

# .global宣言
プログラムで使うすべての関数名を，`.global`に続けてカンマ区切りで挙げる．  

`.global`と関数名の間は，半角スペースで区切る．  
カンマの前後には必ず関数名を書く．  
連続するカンマ，先頭や末尾のカンマは書けない．  
`.global`宣言より前には，空行とコメント行だけを書ける．  

# 数値の書き方
数値は，とくに指定がなければ10進数として扱う．  
末尾に`b`・`o`・`h`を付けると，それぞれ2進数・8進数・16進数として扱う(例: `1010b`・`17o`・`fh`)．  
負の値は，イミディエイトデータの位置にだけ，10進数で書ける(例: `-4`)．  

# レジスタの書き方
レジスタは`r`に続けてレジスタ番地を書く(例: `r10`)．レジスタ番地は，レジスタを指す番号である．  
レジスタ番地の書き方は数値と同じで，とくに指定がなければ10進数，末尾に基数を表す文字があればその基数で扱う(例: `r10h`は`r16`と同じレジスタ)．  
各レジスタ番地のレジスタの役割は[qurge/cpu/register.md](../../qurge/cpu/register.md)を参照．  

# 関数のPC
イミディエイトデータの位置に関数名を書くと，その関数の先頭の命令のPCの値を表す．  
PCは命令の位置を表す番号であり，プログラムの先頭の命令を0として数える．  
メモリの番地とは異なる．  
関数のPCをレジスタへ載せ，そのレジスタを使って関数を呼び出す場合に使う([pyntaxis/language/instruction.md](instruction.md)の「ジャンプ系(J系)」を参照)．  

`main`のPCは書けない．  
`jmp`と分岐系の命令の飛び先には，関数名を書けない．  
飛び先には局所ラベルだけを書ける．  

# 関数名にできない綴り
次の綴りは，ほかの書き方と区別できないため，関数名にできない．  

- 数値として読める綴り(例: `fh`・`-5`): 数値と区別できない  
- レジスタとして読める綴り(例: `r5`): レジスタと区別できない  
- `.`で始まる綴り: 局所ラベルと区別できない  
- 上記のほか，数字や`-`で始まる綴り(例: `2x`): イミディエイトデータの位置で，数値の書き誤りとみなす
