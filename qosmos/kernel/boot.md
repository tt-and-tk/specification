# 起動の手順
この文書は，Qosmosが起動するときの手順を説明する．  
起動時に出力される行と，失敗したときの対処は，[qosmos/user/boot.md](../user/boot.md)を参照．  

Qosmosは，電源を入れたとき(SRSTのボタンを押したときを含む)と，`reboot`を実行したときに，次の順に起動する．  

1. ストレージの項目: SDカードを初期化し，続いてカード上のFAT32ファイルシステムをマウントする(「ストレージの項目」を参照)  
2. telnetでの接続を閉じる(`reboot`のとき．[qosmos/kernel/console.md](console.md)の「コマンドが接続を閉じる場合」を参照)  
3. ネットワークの項目: Ethernetモジュールをリセットし，続いてネットワークの設定を書き込む(「ネットワークの項目」を参照)  
4. OS名を出力する．ストレージの項目が失敗していれば，`reboot`でやり直せることを伝える行も出力する  
5. プロンプトを表示し，コマンドを受け付け始める．telnetでの接続も受け付け始める  

- 2つの項目は互いに依存しないため，前の項目が失敗しても後の項目は実行する  
- 機器とのやり取りの段階ごとに(マウントは1つの段階として)，成否を1行ずつコンソールへ出力する  
- 失敗した段階では理由を出力し，同じ項目の以降の段階は実行しない  
- SDカードの段階と，Ethernetモジュールのリセットの段階の理由には，判定に使った機器の応答値を添える  
- ストレージの項目の成否は，終了状態として保持する([qosmos/user/shell.md](../user/shell.md)の「終了状態」を参照)．ネットワークの項目の成否は含めない．失敗しても，接続を受け付けられるまでやり直すためである([qosmos/kernel/console.md](console.md)の「設定のやり直し」を参照)  

# ストレージの項目
SDカードは，Arduino互換ヘッダのSPIのピンをソフトウェアで駆動して読み書きする([qurge/board.md](../../qurge/board.md)の「SDカードのシールド」を参照)．  
次の段階を順に行う．  

1. リセット(CMD0): カードをSPIモードへ切り替えてリセットする．アイドル状態を表す応答(`0x01`)が返らなければ失敗とする．カードが差さっていない場合は，無応答(`0xff`)になる  
2. 電圧確認(CMD8): 2.7〜3.6Vで動くかを問い合わせる．応答が`0x01`で，問い合わせた電圧範囲とチェックパターン(`0x01`・`0xaa`)がそのまま戻れば成功とし，それ以外は失敗とする．パターンが戻らない場合の理由に添える値は，戻った電圧範囲とチェックパターンの2バイトとする．SD v1のカードはこの問い合わせを拒否するため，ここで失敗する  
3. 初期化完了待ち(ACMD41): カードに内部の初期化を始めさせる．初期化中を表す応答(`0x01`)と完了を表す応答(`0x00`)以外が返った場合と，規格上の上限である1秒を過ぎても完了が返らない場合に失敗とする  
4. カード種別(CMD58): カードの種別を読み出す．応答が`0x00`以外の場合と，SDSCである場合に失敗とする．SDSCである場合の理由に添える値は，種別を表すOCRの最上位バイトとする．成功の行には，SDSCでないことを表す種別名`SDHC/SDXC`を添える  
5. マウント: カードから読み出せない場合と，FAT32ファイルシステムが見つからない場合に失敗とする([qosmos/kernel/filesystem.md](filesystem.md)を参照)  

初期化を始める前に，それまでマウントしていたファイルシステムを外す．  
初期化に失敗したときに，前のカードのファイルシステムを使い続けないためである．  

# ネットワークの項目
Ethernetモジュール(W5100S)は，SPIで制御する([qosmos/kernel/network.md](network.md)を参照)．  
次の段階を順に行う．  

1. リセット: モジュールをハードウェアリセットし，動き出すまで待ってからバージョンを読み出す．W5100Sの値(`0x51`)でなければ失敗とする．モジュールが接続されていない場合は，無応答(`0xff`)になる  
2. ネットワークの設定: 設定の値([qosmos/kernel/network.md](network.md)の「設定」を参照)を書き込み，読み戻した値が1つでも異なれば失敗とする．成功の行には，設定したIPアドレスを添える  

成功は設定を書き込めたことを表し，ケーブルの接続やリンクの確立は確かめない．  

# 起動の行が届く端末
電源を入れたときは，telnetで接続した端末が無いため，起動の行はUARTで接続した端末にだけ届く．  
`reboot`のときは，ネットワークの項目の前に接続を閉じるため，ストレージの項目の行は両方の端末に届き，ネットワークの項目の行とOS名はUARTで接続した端末にだけ届く．
