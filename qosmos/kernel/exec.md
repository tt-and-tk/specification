# 実行ファイルを動かす仕組み
この文書は，シェルが実行ファイルを読み込んで動かし，終わらせる仕組みを説明する．  
実行ファイルを作る人向けの説明は，[qosmos/program/executable.md](../program/executable.md)を参照．  

# 実行の手順
シェルは，次の順に実行ファイルを動かす．  

1. `/bin`から実行ファイルを探し，大きさを確かめる([qosmos/program/executable.md](../program/executable.md)の「実行できない場合」を参照)  
2. 実行ファイルの内容を，領域([qosmos/kernel/memory.md](memory.md)の「実行ファイルの領域」を参照)の先頭から書き写す  
3. telnetで接続した端末へ，ためた出力を送る  
4. 領域をUBASE・USIZEに，システムコールハンドラの番地をKENTRYに，例外ハンドラの番地をEENTRYに書き込む([qurge/cpu/register.md](../../qurge/cpu/register.md)を参照)  
5. 実行ファイルへ入る先として，領域の先頭の命令(領域の中のPC 0)をKRETに書き込む  
6. コマンド名と引数を引数の置き場に置き，SPを決める(「引数の置き方」を参照)  
7. カーネルモードのSPを控えてから，SPを引数を置いて決めた値にし，SYSRET命令でユーザーモードへ移る  
8. 実行ファイルが終了のシステムコールを実行すると，渡された値を終了状態とし([qosmos/user/shell.md](../user/shell.md)の「終了状態」を参照)，プロンプトを表示して次の入力を待つ  

読み込みの途中で読み出しに失敗した場合は，領域に書き写した内容は途中のまま残り，実行はしない．  

# 引数の置き方
コマンド名と引数は，シェルの入力の解析([qosmos/user/shell.md](../user/shell.md)の「入力の解析」を参照)と同じく半角空白で区切り，区切りの空白は文字列に含めない．  
実行ファイルが始まる時点の引数の置き場は，次のとおりである．  

| 位置 | 内容 |
|:-|:-|
| 領域の末尾 | コマンド名と各引数の文字列(ヌル終端)を，入力した順に並べたもの |
| 文字列の下(4バイト境界に揃える) | `argv`の配列．各文字列の先頭の領域の中の番地を並べ，最後に`nullptr`を置く．`argv[0]`はコマンド名(入力したとおりの綴り)である |
| 配列のすぐ下の4バイト | SPが指す位置．CALLが戻り先を積む位置にあたるが，値は不定で，戻り先としては使えない |
| SP-8 | `argc`(`int`)．コマンド名と引数を合わせた数(1以上) |
| SP-4 | `argv`(`char **`)．`argv`の配列の先頭の領域の中の番地 |

`argc`・`argv`の位置は，2つの引数を渡してCALLした直後の引数の位置と同じである．  
このため，Pynesisの`main`は，ほかの関数と同じ呼び出し規約で引数を読める([pynesis/compiler/call.md](../../pynesis/compiler/call.md)の「実行ファイルのmain」を参照)．  

# 終了の手順
実行ファイルが終了のシステムコールを実行すると，システムコールハンドラ([qosmos/kernel/syscall.md](syscall.md)を参照)は次のように戻る．  

1. SPを，実行ファイルへ入る前に控えたカーネルモードのSPに戻す  
2. 渡された値を終了状態として，実行ファイルへ入る処理の呼び出し元へ戻る  

実行ファイルへは戻らない．  

# 例外を起こした場合
実行ファイルが例外を起こすと，CPUはカーネルモードで例外ハンドラへ飛ぶ([qurge/cpu/mode.md](../../qurge/cpu/mode.md)の「ユーザーモードの例外」を参照)．  
例外ハンドラは，SPを空のカーネルモードのスタックにしてから戻ろうとし，カーネルモードの例外でCPUを停止させる．  
何もしなければ，例外を起こした実行ファイルの状態のまま，OSを続けてしまうためである．  

実行ファイルだけを終わらせてシェルへ戻る処理は，qurgeリポジトリ issue #341で置き換える予定である．  

# SPを書き換える関数
実行ファイルへ入る処理と，システムコールハンドラ・例外ハンドラは，SPを書き換える．  
これらの関数は，フレームを持たないよう，引数・ローカル変数を持たず，値はグローバル変数に置く([pynesis/language/hardware.md](../../pynesis/language/hardware.md)の「SPへ書き込める関数」を参照)．
