# ファイルシステムの仕組み
この文書は，QosmosがSDカード上のFAT32ファイルシステムを扱う仕組みのうち，利用者向けの文書([qosmos/user/file.md](../user/file.md)を参照)に書いていないものを説明する．  

# マウント
起動時のストレージの項目([qosmos/kernel/boot.md](boot.md)の「ストレージの項目」を参照)の最後の段階で，カード上のFAT32ファイルシステムをマウントする．  

- カードの先頭のブロックを読み，第1パーティションの種別がFAT32(`0x0B`または`0x0C`)であれば，そのパーティションの先頭からファイルシステムを読む  
- パーティションを持たないカードは，カードの先頭からファイルシステムが始まるものとして読む  
- 読み出せない場合は`cannot read card`，FAT32のファイルシステムとして読めない場合(セクタ長が512バイトでない場合を含む)は`no FAT32 file system`の理由で失敗する  

# 空きクラスタ数
ファイルシステムが記録している空きクラスタ数は，マウントしてから最初にファイル・ディレクトリの領域を確保または解放する時点で，「不明」を表す値にする．  
以降は更新しない．  
パソコンは，次に差したときに数え直す．  

# 書き込みの順序
`write`コマンドとファイルを書き込むシステムコールは，新しい内容を元の内容とは別の空きへ書き終えてから，ファイルの記録を差し替え，元の内容を解放する．  
このため，差し替えより前に失敗すれば，ファイルは元の内容のまま残る([qosmos/user/command.md](../user/command.md)の「write」を参照)．
