# ネットワーク
Qosmosは，Ethernetモジュール(W5100S)を通してLANにつながる．  
モジュールを制御するレジスタは，[qurge/cpu/register.md](../../qurge/cpu/register.md)の`6'h26`を参照．  
モジュールの初期化の段階は，[qosmos/kernel/boot.md](boot.md)の「ネットワークの項目」を参照．  

# 設定
起動時に次の値を設定する．  
値はQosmosのソースに固定しており，変えるにはROMを作り直す．  
DHCPによる自動取得は行わない．  

| 設定 | 値 |
|:-|:-|
| MACアドレス | `02:00:00:00:00:01`(ローカル管理アドレス) |
| IPアドレス | `192.168.10.200` |
| サブネットマスク | `255.255.255.0` |
| ゲートウェイ | `192.168.10.1` |

# pingへの応答
`ping`(ICMPのエコー要求)には，モジュールが自動で応答する．  
CPUの処理を介さないため，シェルの入力待ちの間も，実行ファイルの実行中も応答する．  
リンクが確立していなければ応答しない．  

# TCP
- TCPの接続の確立・再送・切断は，モジュールが行う  
- Qosmosは，接続の待ち受け・受け付け，データの送受信，切断の検出を行う  
- Qosmosは接続を待ち受ける側だけを担い，自分から接続しには行かない  
- 同時に扱う接続は1つで，シェルのコンソールとして使う([qosmos/kernel/console.md](console.md)の「接続の待ち受け」を参照)  

## 相手が応答しなくなった場合
相手が切断を伝えずに応答しなくなった場合(ケーブルが抜けた場合など)は検出せず，接続中のままになる．  
その間は，別の相手からの接続を受け付けない．  
送信中であれば，モジュールの再送のタイムアウトで接続が切れたとみなす．
