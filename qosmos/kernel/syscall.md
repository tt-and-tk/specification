# システムコールの受け付け
実行ファイルから使う方法は，[qosmos/program/syscall.md](../program/syscall.md)を参照．  

# 受け付けの手順
実行ファイルがPyntaxisの`syscall`を実行すると，CPUはカーネルモードにして，KENTRYが示すシステムコールハンドラへ飛ぶ([qurge/cpu/mode.md](../../qurge/cpu/mode.md)の「動作状態の切り替え」を参照)．  
システムコールハンドラは，次の順に処理する．  

1. 実行ファイルのSPを控え，SPをカーネルモードのスタックへ切り替える．切り替えるまでは，関数を呼ばない．SPが領域の中の番地のままで，カーネルモードではそのまま使えないためである  
2. 控えたSPから並べた値を読む(「並べた値の読み出し」を参照)  
3. 番号に対応する機能を実行し，戻り値を戻り値の置き場へ書き込む  
4. SPを実行ファイルのスタックへ戻し，組み込み関数`sysret`で，実行ファイルのPyntaxisの`syscall`の次の命令へ戻る  

終了の機能(番号5)では，戻り値を書き込まず，実行ファイルへも戻らない([qosmos/kernel/exec.md](exec.md)の「終了の手順」を参照)．  

OSは，カーネルモードのスタックで機能を実行するため，実行ファイルのスタックを使わない．  
CPUはPyntaxisの`syscall`・`sysret`でレジスタを切り替えないため，機能を実行した後のr0〜r15とRAXの値は保たれない．  

# 並べた値の読み出し
実行ファイルが並べた値は，控えたSPが指す領域の中の番地から読む．  
並べた値が次の場合は，番号に対応する機能を実行しない．  

- SPが4の倍数でない場合と，並べた24バイトが領域に収まらない場合は，値を読むことも戻り値を書き込むこともできない．このため，どの機能も実行せずに実行ファイルへ戻る  
- 未定義の番号であれば，エラー`-1`を戻り値とする  

# 番地の変換と検査
実行ファイルが渡す番地は，領域の中の番地である．  
カーネルモードのOSは番地を変換されないため，OSが自分で変換する．  

1. 番地から，機能が読み書きする範囲が領域に収まるかを確かめる  
2. 収まれば，領域の先頭の番地を足して，メモリの番地へ変換してから読み書きする  
3. 領域の外へはみ出す場合は，読み書きを行わずにエラー`-2`を返す  

領域の外をカーネルモードで読み書きすると，OSのデータを壊すか，CPUが停止するためである．  
実行ファイルが`int`で渡した負の番地と`nullptr`は，符号なしの値として領域の大きさを超えるため，領域の外として扱う．  

# エラーの値への変換
ファイルを扱う機能の失敗は，実行ファイルへ返すエラーの値([qosmos/program/syscall.md](../program/syscall.md)の「エラー」を参照)へ変換する．  
実行ファイルへは，ファイルシステムの内部の区別を見せず，実行ファイルが対処を変えうる種類だけに分けて返す．
