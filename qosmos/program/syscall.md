# システムコール
実行ファイルは，システムコールを通してOSの機能を呼び出す．  
Pynesisでは，ライブラリ`lib/syscall.pn`(`qurge`の`mypc.srcs/pn/lib/syscall.pn`)を取り込めば，各機能を関数として呼べる．  

```c
#include "lib/syscall.pn"

char buf[64];

int main(void) {
    int n = file_read("memo.txt", buf, 64);   // ファイルを読み込む
    if (n < 0) {
        console_print("cannot read\n");       // エラーの表示は実行ファイルが行う
        return 1;
    }
    console_write(buf, n);                    // 読み込んだ内容を出力する
    return 0;
}
```

| 番号 | 機能 | ライブラリの関数 | 成功したときの戻り値 |
|:-|:-|:-|:-|
| 0 | ファイルの大きさを調べる | `file_size(name)` | ファイルのバイト数 |
| 1 | ファイルの内容を丸ごと読み込む | `file_read(name, buf, size)` | 読み込んだバイト数 |
| 2 | ファイルの内容を丸ごと書き込む | `file_write(name, data, length)` | `0` |
| 3 | コンソールから1行を受け取る | `console_read(buf, size)` | 格納した文字数 |
| 4 | コンソールへ出力する | `console_write(data, length)` | `0` |
| 5 | 実行ファイルを終える | なし(Pynesisでは`main`の終了で呼ばれる) | 戻らない |

戻り値は，0以上なら成功，負の値ならエラーを表す(「エラー」を参照)．  
文字列はヌル終端とする．  
呼び出した後は，汎用レジスタの値は保たれない．  
Pynesisでは，コンパイラが退避と復元を行う．  

OSは，コンソールへ出力する機能に渡されたバイト列と，1行を受け取る間のエコーのほかは，コンソールへ何も出力しない．  
エラーを表示するかどうかは，実行ファイルが決める．  

番号とエラーの値は，ライブラリが取り込む`syscall_number.pn`に定数として定義されている．  
番号を指定して機能を呼ぶ場合は，組み込み関数`syscall`を使う([pynesis/language/builtin.md](../../pynesis/language/builtin.md)の「システムコールを呼ぶ組み込み関数」を参照)．  

## ライブラリのほかの関数
`console_print(text)`は，ヌル終端の文字列をコンソールへ出力する．  
文字数は関数の中で数えるため，渡さなくてよい．  

## ファイルを扱う機能に渡す名前
ファイルを扱う機能に渡す名前は，組み込みコマンドと同じく，シェルの現在のディレクトリの直下にあるファイルの名前だけを指定できる([qosmos/user/shell.md](../user/shell.md)の「現在のディレクトリ」，[qosmos/user/file.md](../user/file.md)の「名前の規則」を参照)．  

## 渡す番地
名前・読み込み先・書き込む内容・格納先・出力するバイト列は，番地で渡す．  
番地は，次の範囲が実行ファイルの領域に収まる必要がある．  

- 名前: ヌル終端まで  
- 読み込み先・書き込む内容・格納先・出力するバイト列: 番地から，渡したバイト数の範囲  

領域の外へはみ出す場合は，読み書きを行わずにエラー`-2`を返す．  

`nullptr`は領域の外を指す値のため，渡すとエラー`-2`になる．  
大きな読み込み先・格納先は，グローバル変数に置く．スタックに置くと，スタックを使い切るおそれがあるためである．  

# ファイルの大きさを調べる
`file_size(name)`は，ファイル`name`のバイト数を返す．  

# ファイルの内容を丸ごと読み込む
`file_read(name, buf, size)`は，ファイル`name`の内容を，`size`バイトの読み込み先`buf`へ書き写し，読み込んだバイト数を返す．  
内容をそのまま書き写し，ヌル終端は付けない．  

内容が読み込み先より大きい場合は，読み込み先へ何も書き込まずにエラーを返す．  
ファイルの大きさは，必要なら`file_size`で調べてから読み込む．  
読み出しの途中で失敗した場合は，読み込み先に書き写した内容が途中のまま残る．  

# ファイルの内容を丸ごと書き込む
`file_write(name, data, length)`は，ファイル`name`の内容を，`data`から`length`バイトで丸ごと置き換える．  
ファイルが無ければ作成する．  

失敗した場合に残る内容を含め，`write`コマンドと同じ動作になる([qosmos/user/command.md](../user/command.md)の「write」を参照)．  
元の内容が占めている領域は新しい内容の書き込みに使えないため，空きが足りなければ，同じ大きさや小さい内容への書き換えでもエラーになる．  

# コンソールから1行を受け取る
`console_read(buf, size)`は，コンソールから改行までの1行を受け取り，`size`バイトの格納先`buf`へ格納する．  
格納した文字数を返す．  
改行を除き，ヌル終端を付けて格納する．  
格納できる文字数は`size`-1で，それを超えた分は捨てる．  
シェルと同じく，エコーと1行の編集を行う([qosmos/user/console.md](../user/console.md)の「1行の入力」を参照)．  

telnetでの接続が切れてもエラーにはせず，UARTで接続した端末から続けて受け取る．  
受け取る途中で新たな端末がtelnetで接続した場合は，受け取り途中の行を捨てて受け取り直す([qosmos/user/console.md](../user/console.md)の「新たにtelnetで接続したとき」を参照)．  

# コンソールへ出力する
`console_write(data, length)`は，`data`から`length`バイトをコンソールへ出力する．  
シェルの出力と同じく変換する([qosmos/user/console.md](../user/console.md)の「出力の変換」を参照)．  
呼び出すたびに，ためた出力をtelnetで接続した端末へ送る．  

telnetでの接続が切れても，エラーにはしない．  
接続が切れると，telnetで接続した端末へまだ送っていない出力と，以降の出力は失われる．  

# 実行ファイルの終了
番号5の機能は，実行ファイルを終え，シェルへ戻る．  
渡した値(アセンブリから呼ぶ場合は引数`a`．「アセンブリから呼ぶ場合」を参照)が，シェルの終了状態になる([qosmos/user/shell.md](../user/shell.md)の「終了状態」を参照)．  
OSは実行ファイルへ戻らない．  

Pynesisでは，コンパイラが`main`の終了でこの機能を呼ぶ([pynesis/compiler/call.md](../../pynesis/compiler/call.md)の「実行ファイルのmain」を参照)．  

# エラー
| 値 | 条件 |
|:-|:-|
| `-1` | 未定義の番号を渡した |
| `-2` | 引数の値が不正(番地が領域の外を指すか，バイト数が機能の受け付ける範囲の外にある．ファイルを扱う機能は0以上，コンソールを扱う機能は1以上のバイト数を受け付ける) |
| `-3` | ファイルが読み込み先に収まらないか，大きさが`int`の正の値で表せない |
| `-4` | 指定した名前のファイルが無い |
| `-5` | 指定した名前がディレクトリを指す |
| `-6` | 名前が規則に合わない |
| `-7` | SDカードに空きが無い |
| `-8` | ファイルを扱う機能が`-3`〜`-7`のほかの理由で失敗した(SDカードを読み書きできない場合や，ファイルシステムの記録が壊れている場合など) |

# アセンブリから呼ぶ場合
Pyntaxisの`syscall`([pyntaxis/language/instruction.md](../../pyntaxis/language/instruction.md)の「動作状態を切り替える命令」を参照)を実行する前に，SPが指す番地から次の6つの値を4バイトずつ順に並べておく．  
番地は，領域の中の番地([qosmos/kernel/memory.md](../kernel/memory.md)の「実行ファイルの領域」を参照)を整数として渡す．  

| SPからの位置 | 内容 |
|:-|:-|
| +0 | 戻り値の置き場(OSが書き込む) |
| +4 | 機能の番号 |
| +8〜+20 | 機能に渡す引数`a`〜`d`．機能が使わない引数の値は問わない |

各機能の引数は，次のとおりである．  

| 番号 | 引数 |
|:-|:-|
| 0 | `a`: 名前 |
| 1 | `a`: 名前，`b`: 読み込み先，`c`: 読み込み先のバイト数 |
| 2 | `a`: 名前，`b`: 書き込む内容，`c`: そのバイト数 |
| 3 | `a`: 格納先，`b`: 格納先のバイト数 |
| 4 | `a`: 出力するバイト列，`b`: そのバイト数 |
| 5 | `a`: 終了状態 |

OSは，機能を実行してから戻り値を置き場へ書き込み，Pyntaxisの`syscall`の次の命令へ戻る．  
ただし，SPが4の倍数でない場合と，並べた24バイトが領域に収まらない場合は，どの機能も実行せずに戻る．  
このとき，戻り値の置き場もそのまま残る．  
戻った時点のr0〜r15とRAXの値は保たれない．  
SPは保たれる．  

OSが受け付ける仕組みは，[qosmos/kernel/syscall.md](../kernel/syscall.md)を参照．
