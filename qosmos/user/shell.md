# シェル
シェルは，プロンプト`> `を表示してコンソール([qosmos/user/console.md](console.md)を参照)から1行を受け取り，コマンドとして実行する．  

```
> echo hello
hello
> ls
README.TXT
bin/
> status
0
```

# 入力の解析
受け取った1行を半角空白で区切り，先頭をコマンド名，以降を引数として扱う．  

- コマンド名が組み込みコマンド([qosmos/user/command.md](command.md)を参照)のどれかと一致すれば，そのコマンドを実行する．大文字・小文字を区別して照合する  
- 一致しなければ，同じ名前の実行ファイルを探して実行する([qosmos/program/executable.md](../program/executable.md)の「置き場所と探し方」を参照)  
- どちらも見つからない場合は，`unknown command`のエラーになり，何も実行しない  
- 1行の長さの上限は63文字である．上限を超えた分とバックスペースの扱いは，[qosmos/user/console.md](console.md)の「1行の入力」を参照  

## 区切りの扱い
- 区切りとして扱うのは半角空白だけである．タブなどほかの空白文字は，引数の一部になる  
- コマンド名の手前と引数の間の空白は，何文字でもよい  

## コマンド名が無い行
改行だけの行，空白だけの行，入力した文字をすべてバックスペースで消した行などは，コマンド名が無い行である．  
コマンド名が無い行は，何も実行・出力せず，次のプロンプトを表示する．  

# 現在のディレクトリ
シェルは，現在のディレクトリを1つ持つ．  
名前を引数に取るコマンドと，ファイルを扱うシステムコールは，現在のディレクトリの直下にあるファイル・ディレクトリを対象にする．  

- 2つの端末([qosmos/user/console.md](console.md)を参照)で，同じ現在のディレクトリを共有する．端末がtelnetで接続しても変わらない  
- 起動時(`reboot`による起動のし直しを含む)は，ルートディレクトリから始まる  
- `cd`で移り，`pwd`で確かめる([qosmos/user/command.md](command.md)の「cd」「pwd」を参照)  
- 名前には，現在のディレクトリの直下にあるファイル・ディレクトリの名前を指定する．`cd`には，`.`・`..`も指定できる([qosmos/user/command.md](command.md)の「cd」を参照)．`/`で区切ったパス(`/DOCS`・`DOCS/a.txt`など)は，`/`が名前に使えない文字のため，名前が規則に合わないエラーになる  

# エラーの表示
コマンドがエラーになると，コマンド名を前置したエラーメッセージを出力する(`cat: no such file or directory`など)．  
エラーになったコマンドは，何も行わない．  
例外となるコマンドは，[qosmos/user/command.md](command.md)の各コマンドの節を参照．  

# 終了状態
シェルは，終了状態(整数1つ)を保持する．  
`status`で出力すれば，直前のコマンドの成否を確かめられる．  
出力は符号ありの10進数1行で，負の数は`-`を前置する．  

| 直前に行ったこと | 終了状態 |
|:-|:-|
| 電源を入れたときの起動(まだコマンドを実行していない場合) | ストレージの項目([qosmos/user/boot.md](boot.md)を参照)がすべて成功すれば0，失敗すれば1 |
| 組み込みコマンド | 成功すれば0，エラーになれば1 |
| 実行ファイル | 実行ファイルが終了のシステムコールで渡した値([qosmos/program/executable.md](../program/executable.md)の「終了状態」を参照) |
| 実行ファイルを実行できなかったコマンド([qosmos/program/executable.md](../program/executable.md)の「実行できない場合」を参照) | 1 |

- 組み込みコマンドのエラーには，出力や書き換えの途中で失敗した場合も含む  
- `reboot`(引数なし)は，電源を入れたときと同じく，ストレージの項目が失敗すれば1になる  
- 起動の終了状態には，ネットワークの項目の成否を含めない．失敗しても，telnetでの接続を受け付けられるまでやり直すためである．起動時のEthernetモジュールの結果は，UARTで接続した端末に届く行で確かめる  
- `status`自身は終了状態を変えない．引数を与えてエラーになった場合も変えないため，何度実行しても同じ値を確かめられる  
- コマンド名が無い行は，何も実行しないため終了状態を変えない  
- 実行ファイルが返した1と，実行ファイルを実行できなかった場合の1は区別しない．実行できなかった場合は，その理由がエラーメッセージで出力される
