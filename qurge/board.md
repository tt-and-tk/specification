# 実機の構成
Pynthesisの実機は，PYNQ-Z2ボードに，Arduino Uno互換のピン配置を持つ拡張基板(シールド)を2枚重ねて構成する．この構成で実機を使う手順は，[operation.md](../operation.md)を参照．  

ピンの割り当ては`qurge`の制約ファイル(`mypc.srcs/constrs_1/new/top.xdc`)が持ち，「SDカードのシールド」と「Ethernetモジュールのシールド」の表にある「制約ファイルの信号名」はそのファイルでの名前である．各機器を操作するレジスタのビットの割り当ては[qurge/cpu/register.md](cpu/register.md)を参照．  

# シールドの重ね方
- 下段: SDカードのシールド(「SDカードのシールド」を参照)  
- 上段: Ethernetモジュールのシールド(「Ethernetモジュールのシールド」を参照)．モジュールのRJ-45コネクタ(LANケーブルを挿すコネクタ)は背が高く，上に別のシールドを重ねられないため，最上段に置く  

Arduinoの2×3のSPIヘッダ(ボード上の，D0〜D13とは別のSPI用の6ピンのヘッダ)は，SDカードのシールドから上段のシールドへスタッキングヘッダ(上下に貫通したピンヘッダ)で通している．  

# SDカードのシールド
Qosmosのファイルシステムを置くSDカードを挿すシールドである．  

- 構成: 秋月電子のマイクロSDカードスロットDIP化キット(AE-MICRO-SD-DIP)を，TreedixのArduino用プロトシールドに実装したもの  
- 信号: Arduinoの2×3のSPIヘッダから取る．操作するレジスタは`6'h2a`(Pynesisのハードウェア変数`AR_SPI`)  

| 2×3のヘッダ | 信号 | FPGAのピン | 制約ファイルの信号名 |
|:-|:-|:-|:-|
| 1番 | MISO | W15 | `ck_miso` |
| 2番 | 3.3V | - | - |
| 3番 | SCK | H15 | `ck_sck` |
| 4番 | MOSI | T12 | `ck_mosi` |
| 5番 | SS(カードのCS) | F16 | `ck_ss` |
| 6番 | GND | - | - |

- 電源: カードのVDDは，Arduinoの電源ヘッダJ7の5番(3.3V)から取る  
- 部品: MISOとCSをそれぞれ10kΩで3.3Vへプルアップし，VDDとGNDの間に0.1µFのコンデンサを付けている  
- 5Vピンの切断: このプロトシールドは5Vのバス配線を持ち，SDカードの回路の電源がそのバス上にあった．そのまま挿すとボードの5Vと3.3Vが直結して電源の保護が働き，ボードが起動しないため，シールドの5Vピンを切断している．同種のプロトシールドを使う場合は，回路の各点とArduinoの電源ヘッダJ7の各ピン(5V・3.3V・IOREF(シールドへ信号の電圧を知らせるピン)・VIN(外部電源の入力)・RESET)の間に，意図しない導通がないかを先に確かめる  

# Ethernetモジュールのシールド
Qosmosのコンソール(telnet)に使うEthernetモジュールを載せたシールドである．  

- 構成: WIZnet Ethernet HAT(W5100Sを搭載し，Raspberry Pi Picoと同じピン配置を持つモジュール)を，SDカードのシールドと同じプロトシールドに載せたもの  
- 取り付け: モジュールの両側のピン列をシールドのソケットに挿している．モジュールはシールドより長いため，一部のピンはシールドからはみ出している．配線しているのは，「Ethernetモジュールのシールド」の表にある信号のピンと，同じ節の「電源」「GND」の項に書いた電源・GNDのピンだけで，ほかのソケットはどこにもつながっていない  
- 信号: ArduinoのデジタルピンD8〜D13を，SDカードとは共有しない専用のSPIとして使う．操作するレジスタは`6'h26`(Pynesisのハードウェア変数`ETH_SPI`)．D8〜D13は，ボード上で200Ωの直列抵抗だけを通してFPGAにつながっている  

| Arduinoのピン | FPGAのピン | 制約ファイルの信号名 | モジュールの信号 | モジュールのピン(Picoの物理ピン番号) |
|:-|:-|:-|:-|:-|
| D8 | V17 | `eth_intn`(入力．内部プルアップ) | INTn | 27番 |
| D9 | V18 | `eth_rstn` | RSTn | 26番 |
| D10 | T16 | `eth_csn` | CSn | 22番 |
| D11 | R17 | `eth_mosi` | MOSI | 25番 |
| D12 | P18 | `eth_miso`(入力．内部プルアップ) | MISO | 21番 |
| D13 | N17 | `eth_sck` | SCK | 24番 |

モジュールの信号のうち，INTnはW5100Sの割り込みの出力，RSTnはリセットの入力，CSnはSPIの相手として選ぶための入力であり，いずれもLowで有効である．  

- 電源: J7の5番(3.3V)からモジュールの3V3(36番)へ給電し，VBUS(40番．PicoではUSBから受け取る5Vのピン)は開放にする  
    - 5Vを使わない理由: 下段のSDカードのシールドで5Vピンを切断しており(「SDカードのシールド」を参照)，上段には5Vが届かないため  
    - VBUSを開放して3V3へ外から3.3Vを入れてよい理由: Picoのデータシートにある使い方どおり電池からVSYS(Picoの主電源の入力ピン)へ給電したPicoにモジュールを挿したときも，VBUSは0VのままPicoが3V3へ3.3Vを出力し，モジュールから見て同じ状態になるため  
- GND: モジュールのGNDのうち28番をボードのGNDへつなぐ  
- 部品: D10(CSn)と3.3Vの間に10kΩのプルアップを付け，FPGAの起動前にモジュールが選択されないようにしている．RSTnはモジュール上で4.7kΩでプルアップされている  

# ボード側のピンの注意
Arduinoのアナログピン A0〜A5は，ボード上のXADC(FPGA内蔵のA/D変換器)用の分圧回路(2.32kΩ+1kΩ)を通して常にGNDへつながっている．このため，プルアップが必要な信号には使えない．  

# SRSTのボタン
ボードのSRSTのボタンを押すと，ボードの電源を入れ直したときと同じように，Qosmosが起動からやり直す．ボードのSDカードスロットのすぐ隣にあり，基板に印刷された名前は`SRST`である．シールドを重ねたままで押せる．  

SRSTは，PSをリセットするボタンである．CPUのリセット(CPUをプログラムの先頭から実行し直させる信号．[qurge/memory.md](memory.md)と[qurge/cpu/exception.md](cpu/exception.md)のリセットはこれを指す)とは別のものであり，CPUのリセットはPSから入る．SRSTを押すとPSが起動からやり直し，FSBLがボードのSDカードのBOOT.BINからPLを書き込み直して，CPUのリセットを解除する．書き込み直す間は，PLの書き込みの完了を示すDONEのLEDが消える．  

- TCPの接続は切れる  
- PLを書き込み直すため，メモリの内容もビットストリームが持つ初期値に戻る(CPUのリセットだけではメモリの内容は残る)
