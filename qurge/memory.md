# メインメモリ
QurgeのCPUが読み書きするメインメモリ(以下，メモリと書く)は，番地を指定して値を記憶する装置である．  

# 容量と番地
|項目|仕様|
|:-|:-|
|データバス|32ビット|
|アドレスバス|16ビット|
|容量|8ビットのレジスタ65536本，64KB|

- 番地は，データバス幅(32ビット)で扱う  
- 仕様書では，番地の大きい側を上，小さい側を下と呼ぶ．例えば，スタックが下へ伸びるとは，番地の小さい側へ伸びることを指す  
- 容量は2のべき乗とし，アドレスバス幅は容量をちょうど表現できるビット数とする  
- アドレスバス幅を超える上位ビットが1ビットでも立っている番地は，容量外の番地である．容量外の番地は，折り返して有効な番地とみなさず，不正な番地として扱う(CPUが読み書きする場合の挙動は[qurge/cpu/exception.md](cpu/exception.md)を参照)  

# 読み書き
書き込みと読み込みを別のインターフェースで同時に行える．  
同じ番地に対して同時に書き込み・読み込みすることもできるが，動作は保証しない．  

バースト転送用の仕組み(last信号)は用意されているが，現時点では非対応であり，転送のたびにlast信号を`true`にして単発の転送として扱う．  
詳細仕様(タイミング・last信号の扱い等)自体も未検討である．  

# リセット後の内容
CPUのリセットはメモリの内容を初期化せず，リセット前に書き込まれた値がそのまま残る．  
このため，CPUのリセットの後に書き込む前のメモリの値は，保証されない．  
実機のSRSTのボタンは，CPUのリセットとあわせて，メモリを回路を書き込んだときの値に戻す([board.md](../board.md)の「SRSTのボタン」を参照)．  

# バイトの並びとmask
読み込み・書き込みそれぞれで，maskを使って対象のバイトを指定できる．  
maskのビット幅は4ビットで，1ビットが読み書き対象の1バイトに対応する．  
バイトの並びはリトルエンディアンである．  

次の図は，`address`を起点に読み書きした際，各番地のバイトがレジスタ・データバス上のどのビット位置に対応するかを示す．  
maskのビットi(i=0〜3)は，`address+i`番地に対応する．  

```
31          23          15          7        0
|address + 3|address + 2|address + 1|address|
```

1回の読み込み・書き込みでmaskが対象とするバイト範囲(`address`からmaskの最上位ビットが指す番地まで)は，4バイト境界に揃った同一ワード内に収まっている必要がある．  
ワードをまたぐ`address`とmaskの組み合わせを指定した場合，容量外の番地としての例外にはならず，同一ワード内で折り返した誤った番地を読み書きする．
